# Simulation and control contract v1

## Navigation simulation

World: rectangular strings, `.` free and `#` blocked, 5–40 rows/columns. Rows are north-to-south. Coordinates are metres: x east, y north; cell centres are half-integers, heading is radians counterclockwise from east. Start/goal must be valid free cell centres with full body clearance. Start heading is finite in [-π,π]. Defaults: radius 0.35 m, track 0.32 m, maximum side speed0.6 m/s, maximum yaw1.4 rad/s, wheel acceleration0.5 m/s², dt 0.1 s, steps 2000, beams 24, range 4 m. Bounds: radius 0.1–0.45 m, track 0.2–0.8 m and no wider than the body diameter; speed 0.1–1m/s; yaw 0.2–2rad/s; acceleration 0.1–2m/s²; dt 0.02–0.2s; steps 1–3000; beams 8–64; range 1–8 m. Reject cells×steps>5million, cells×steps×beams>80million or steps×beams>150000. Replay: at most 3001 frames and 4 MiB serialized JSON.

Sensor beams measure the first static obstacle or world boundary exactly. Samples along each visible beam update the private occupancy grid. The planner receives dimensions/private grid/pose/goal only; unknown cells are provisionally traversable. Cardinal BFS replans when a discovered obstacle invalidates the route. A waypoint controller limits desired yaw and side speed. A common interpolation factor limits both wheel acceleration increments while preserving the convex speed/yaw bounds.

For left/right linear side speeds, v=(left+right)/2 and ω=(right-left)/track. Exact constant-speed arcs integrate each tick. The full curved disc is conservatively checked through chord capsules with per-chord sagitta inflation. Unsafe proposed motion is rejected before the state/time advances and terminates as `safety_stop`. This central ground-truth shield is not a realizable physical brake. Other outcomes: `arrived` (within 0.12 m with wheels stopped), `unreachable` (no private-map route even treating unknown as free), or `budget`. Invalid start/goal/configuration rejects input instead of returning a successful run.

Reports contain effective configuration, original map, poses/side speeds/ranges and discovery deltas, plus accepted steps, simulated time, path length, replans, observed counts, maximum accepted speed/yaw/acceleration, rejected motion count and outcome. Accepted-motion collisions are checked invariants, not learned obstacle-avoidance performance. No wall-clock benchmark or physical speed calibration is implied.

## Wired bench protocol

ASCII command: `R1,SEQ,CMD,LEFT,RIGHT,LEASE*HH\n`. CMD is `A`(arm), `M`(move) or `S`(stop); sequence is unsigned16-bit. Left/right are signed PWM units from -180 to 180; lease 100–500 ms. ARM and STOP require zero PWM. CRC8 polynomial0x07, initial0, no reflection/xorout; compute over all bytes before `*`, use two hexadecimal digits. The complete line is at most63bytes excluding newline. Optional CR before LF is accepted. Nonprintable, oversized, invalid, stale or unarmed movement input disarms and commands neutral. Malformed input does not advance sequence. STOP always neutralizes; an invalid/stale STOP still fails closed.

Fresh sequence: delta=(new-old)mod65536 is in1..32767; first valid command may use any sequence. This permits wrap but is neither authentication nor persistent replay protection. A reboot clears sequence state. ARM is explicit and neutral; MOVE refreshes the bounded lease. At `now-lastCommand >= lease`, the watchdog disarms and commands zero immediately. Unsigned32-bit elapsed time handles millis rollover. Normal PWM changes by at most 20 units per 20 ms control update; reversal reaches zero before changing sign. STOP, malformed input and watchdog neutral bypass slew. PWM values are not verified physical wheel speeds.

Telemetry: `T1,SEQ,STATE,LEFT,RIGHT,FAULT*HH\n`, with STATE A or D and current PWM outputs. It is sent after each complete command and periodically. Faults:0none,1invalid,2stale,3watchdog,4overflow,5unarmed. Neither firmware nor host provides a physical safety certification. A hardware supply-cut emergency stop remains independent of software.
